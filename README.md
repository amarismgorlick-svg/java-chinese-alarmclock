# java-chinese-alarmclock
Java automated command line alarm clock with repercussions based on how long alarm is ignored.
## The Problem
When I am up late studying I become super tired and forget to set my morning alarms. I often end up oversleeping and I show up late to my Chinese lecture almost everyday. This causes me to miss important information and sets a bad reputation with my professor.
## How It Works
- [ ] Alarm rings at needed time
- [ ] User can stop alarm
- [ ] Records time it takes to stop alarm repercussion
